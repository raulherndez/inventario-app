# Inventory Control System

This is an inventory management application built with **React**, **Vite**, and **Supabase**. It provides a practical and efficient way to track stock, manage product categories, and handle business inventory parameters.

## Features
- Real-time database integration using Supabase.
- Add, update, and monitor inventory items.
- Organized management of categories, brands, and suppliers.
- Clean and responsive user interface.

## Tech Stack
- **Frontend:** React, Vite, Talwind CSS
- **Backend/Database:** Supabase
